# Baby

100 篇按阅读日排序的原创故事、42 天产后参考菜单（哺乳与不哺乳模式）、详细做法和营养数据来源，以及生产指南。

公开站点：https://wmamba0824.github.io/baby-reading-meals/

生产指南入口：https://wmamba0824.github.io/baby-reading-meals/#birth

生产指南按分娩方式、产前、产中、产后、普通与特需、就诊清单和依据组织，附四张原创 SVG 概念图。资料核查日期 2026-10-11，来源实际发布日期与适用范围在页面内显示，包括中国医学会指南、中国分娩镇痛政策，以及 WHO、NICE、RCOG、NHS 与 CDC 资料。国际指南不是国内具体服务或医保的承诺。

就诊清单根据填写资料生成讨论问题，不诊断、不预测分娩概率、不作试产许可判断。资料仅在当前页面内存中；切换主题或离开生产指南、刷新、清除都会移除。复制和打印需用户主动操作。

这是独立静态阅读站，保留故事收藏、阅读历史和字体设置。社区菜谱使用已有公开资料缓存；实时采集需单独部署后端。

故事用于亲子交流，不承诺胎教提升智力；菜单是营养估算示例，非个人处方。生产指南不能替代检查及个人医嘱。

开发验证：安装 package.json 内开发依赖后，运行 `npm run test:birth`、`npm run test:navigation`、`npm run test:meals`。DOM 测试不证明浏览器视觉布局；发布时另核对匿名可访问的线上资产。
