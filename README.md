# Baby

100 篇按阅读日排序的原创故事、生产指南、42 天产后参考菜单（哺乳与不哺乳模式），以及母婴产后时间轴。

公开站点：https://wmamba0824.github.io/baby-reading-meals/

生产指南入口：https://wmamba0824.github.io/baby-reading-meals/#birth

产后时间轴：https://wmamba0824.github.io/baby-reading-meals/#postpartum

默认入口为“今日”，导航顺序为“今日 → 育儿故事 → 生产指南 → 月子餐 → 产后时间轴”。原有故事、菜单、指南与时间轴的深链接保持可用，故事书架入口为 `#stories`。

今日首页汇总餐谱、阅读日程、当前阶段事项及日常照护。预产期和实际出生日期由用户主动填写，过预产期也不会自动认定已出生。出生当天显示日龄 0 天，对应餐谱第 1 天；超过 42 天后，餐谱循环明确标为家常备餐灵感，不表示新的医学恢复分期。孕期仅展示产后餐谱预览，不作为孕期专用食谱。按日历日定位阶段，小时窗口按出生时刻、公卫访视按出院日起算，个体安排始终以医院计划为准。

首页设置使用当前浏览器的 `baby:today:v1`，餐谱份量使用 `baby:feeding:v1`，均不上传服务器。故事安排有独立开始日期和起始篇目，宝宝日期变化不重置，旧收藏及阅读进度保留在原存储键。资料清除、换浏览器或禁用存储会影响保存；页面会显示保存失败提示。每日跨零点或重新回到页面时更新今日内容。

产后时间轴按首24小时、第2～3天、出院前后／首周、第7～14天、满月、第6周及之后排列，支持全部／宝宝／妈妈筛选、独立阶段链接和打印。筛查、接种按出生时间，国内公卫访视按出院时间；各地采样窗口、特殊儿复采和个体复诊在相关卡片中区分。包括妈妈的伤口、情绪、乳房、避孕及有GDM者随访，不重复编排月子餐。每项附来源，资料核查2026-10-15。

生产指南按分娩方式、产前、产中、产后、普通与特需、就诊清单和依据组织，附四张原创 SVG 概念图。资料核查日期 2026-10-11，来源实际发布日期与适用范围在页面内显示，包括中国医学会指南、中国分娩镇痛政策，以及 WHO、NICE、RCOG、NHS 与 CDC 资料。国际指南不是国内具体服务或医保的承诺。

就诊清单根据填写资料生成讨论问题，不诊断、不预测分娩概率、不作试产许可判断。资料仅在当前页面内存中；切换主题或离开生产指南、刷新、清除都会移除。复制和打印需用户主动操作。

这是独立静态阅读站，保留故事收藏、阅读历史和字体设置。社区菜谱使用已有公开资料缓存；实时采集需单独部署后端。

故事用于亲子交流，不承诺胎教提升智力；菜单是营养估算示例，非个人处方。生产指南不能替代检查及个人医嘱。

开发验证：安装 package.json 内开发依赖后，运行 `npm run test:birth`、`npm run test:postpartum`、`npm run test:navigation`、`npm run test:meals`。DOM 测试不证明浏览器视觉布局；发布时另核对匿名可访问的线上资产。
